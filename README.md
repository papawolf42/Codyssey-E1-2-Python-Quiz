# 리누스 토발즈 명언 퀴즈

## 프로젝트 개요

Python 터미널에서 실행하는 4지선다형 명언 퀴즈 게임입니다.
메뉴에서 퀴즈를 풀거나 새로운 문제를 추가하고, 등록된 문제 목록과 최고 점수를 확인할 수 있습니다.
추가한 퀴즈와 최고 점수는 `state.json`에 저장되어 프로그램을 다시 실행해도 유지됩니다.

## 퀴즈 주제와 선정 이유

이번 과제에서 클래스를 활용한 객체지향 구조를 배우면서, 리누스 토발즈가 C++과 프로그래밍에 관해 이야기한 관점들이 재미있게 느껴졌습니다.
코딩을 배우는 과정에서 그의 발언을 읽고 영감과 재미를 함께 얻을 수 있을 것 같아 명언 퀴즈를 주제로 선택했습니다.

정답이 아닌 선택지도 해당 인물이 말했을 법한 주제와 말투로 배치하여 답이 바로 드러나지 않도록 구성했습니다.
영어 원문의 의미를 함께 확인할 수 있도록 각 선택지 아래에 한국어 번역을 표시했습니다.

## 실행 환경

- Python 3.11.13
- Python 표준 라이브러리 `json` 사용
- 별도의 외부 패키지 설치 없음

## 실행 방법

터미널에서 프로젝트 디렉터리로 이동한 뒤 Python 버전을 확인하고 프로그램을 실행합니다.

```bash
python3 --version
python3 main.py
```

실행된 메뉴에서 1부터 5까지의 번호를 입력해 기능을 선택합니다. 프로그램을 정상 종료하려면 5번을 선택합니다.

## 기능 목록

- **퀴즈 풀기:** 등록된 퀴즈를 순서대로 출제하고 정답과 오답을 알려줍니다. 한 문제당 10점으로 결과를 계산하고 최고 점수를 갱신합니다.
- **퀴즈 추가:** 문제, 선택지 4개와 정답 번호를 입력받아 새로운 퀴즈를 추가하고 바로 저장합니다.
- **퀴즈 목록:** 등록된 모든 퀴즈의 질문을 번호와 함께 보여줍니다. 퀴즈가 없으면 안내 문구를 출력합니다.
- **점수 확인:** 저장된 최고 점수와 현재 전체 문제의 총점을 보여줍니다. 아직 플레이하지 않았으면 기록이 없음을 안내합니다.
- **종료:** 현재 퀴즈와 최고 점수를 저장하고 프로그램을 종료합니다.

### 입력과 파일 오류 처리

- 빈 입력, 문자가 입력된 숫자 항목과 허용 범위를 벗어난 번호는 다시 입력받습니다.
- `state.json`이 없으면 기본 퀴즈 5개로 시작합니다.
- JSON이 손상되거나 파일을 읽을 수 없으면 안내 후 기본 퀴즈로 복구합니다.
- 파일을 쓸 수 없으면 오류를 안내하고 프로그램을 유지합니다.
- `Ctrl+C` 또는 EOF로 입력이 중단되면 가능한 상태를 저장한 뒤 안전하게 종료합니다.
