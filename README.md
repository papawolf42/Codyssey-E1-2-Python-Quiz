# 리누스 토발즈 명언 퀴즈

## 프로젝트 개요

Python 터미널에서 실행하는 4지선다형 명언 퀴즈 게임입니다.
메뉴에서 퀴즈를 풀거나 새로운 문제를 추가하고, 등록된 문제 목록과 최고 점수를 확인할 수 있습니다.
추가한 퀴즈와 최고 점수는 `state.json`에 저장되어 프로그램을 다시 실행해도 유지됩니다.

## 퀴즈 주제와 선정 이유

이번 과제에서 클래스를 활용한 객체지향 구조를 배우면서, 리누스 토발즈가 C++과 프로그래밍에 관해 이야기한 관점들이 재미있게 느껴졌습니다.
코딩을 배우는 과정에서 그의 발언을 읽고 영감과 재미를 함께 얻을 수 있을 것 같아 명언 퀴즈를 주제로 선택했습니다.

정답이 아닌 선택지도 해당 인물이 말했을 법한 주제와 말투로 배치하여 답이 바로 드러나지 않도록 구성했습니다.
영어 원문의 의미를 함께 확인할 수 있도록 각 선택지 아래에 한국어 번역을 표시했습니다.

## 실행 환경

- Python 3.11.13
- Python 표준 라이브러리 `json` 사용
- 별도의 외부 패키지 설치 없음

## 실행 방법

터미널에서 프로젝트 디렉터리로 이동한 뒤 Python 버전을 확인하고 프로그램을 실행합니다.

```bash
python3 --version
python3 main.py
```

실행된 메뉴에서 1부터 5까지의 번호를 입력해 기능을 선택합니다. 프로그램을 정상 종료하려면 5번을 선택합니다.
